# 🇰🇷 Wcam - Wplace 태극기 감시 봇

**Wcam**은 세계지도 픽셀 아트 사이트 [wplace.live](https://wplace.live)에 그려진 태극기(독도, 서울, 백두산)가 다른 사용자에 의해 훼손되는지 자동으로 감시하고, 변화가 감지되면 즉시 디스코드로 알려주는 봇입니다.

> [!WARNING]
> 화이트리스트 시스템을 사용 중입니다. 서버에 봇을 초대하고자 한다면 [서포트 서버](https://discord.gg/utxeK62GJV)에 참여하여 사용승인을 받아주세요.

---

## ✨ 주요 기능

- 🔍 **자동 감시**: 30초마다 지정된 3개 구역(독도/서울/백두산)의 실시간 타일 이미지를 가져와 기준 이미지와 픽셀 단위로 비교합니다.
- 🚨 **실시간 알림**: 일치율이 서버별로 설정한 임계값 아래로 떨어지면, 지정한 채널에 이미지·통계와 함께 임베드 알림을 보냅니다. (역할 멘션 지원)
- 🕵️ **훼손 계정 참고 정보**: 알림 발생 시 wplace의 공개 API를 통해 변경된 픽셀 일부를 샘플 조회해, 실제로 그 자리를 칠한 계정(닉네임·동맹명)을 알림에 함께 표시합니다. 전수조사가 아닌 샘플 기반 참고 정보이므로 오탐 가능성이 있습니다.
- ⏱️ **쿨다운**: 같은 구역에 짧은 시간 안에 알림이 반복되지 않도록 서버별 쿨다운 시간을 설정할 수 있습니다.
- 🎬 **타임랩스 녹화**: 원하는 구역을 일정 시간 동안 캡처해 타임랩스 영상(MP4)으로 만들어 DM으로 받을 수 있습니다.
- 📊 **그래프**: 최근 30분간의 일치율 변화를 그래프로 확인할 수 있습니다.
- ✅ **화이트리스트**: 개발자가 승인한 서버에서만 봇이 활동하도록 제한할 수 있습니다.
- 🌐 **상태 API**: 외부 대시보드나 헬스체크에서 쓸 수 있는 간단한 REST API를 함께 제공합니다. API 사용을 원하면 [서포트 서버](https://discord.gg/utxeK62GJV)에서 요청할 수 있습니다.

## 🤖 명령어 목록

모든 명령어는 `w!`로 시작합니다. (예: `w!ping`)

### 일반 명령어

| 명령어 | 설명 |
|---|---|
| `w!ping` | 봇의 응답 속도를 확인합니다. |
| `w!help` | 사용 가능한 명령어 목록을 보여줍니다. |
| `w!status` | 서버 설정값(채널, 역할, 임계값 등)을 한눈에 보여줍니다. |
| `w!flag [구역]` (단축 `w!f`) | 특정 구역의 실시간 상태와 불일치 픽셀을 확인합니다. |
| `w!history [구역]` (단축 `w!h`) | 최근 30분간의 일치율 변화를 그래프로 보여줍니다. |
| `w!record [구역] [기간]` (단축 `w!r`) | 지정한 구역을 일정 시간 동안 녹화해 타임랩스 영상을 만듭니다. (기간 예: `10m`, `1h`) |
|`w!record (타일X) (타일Y) (로컬X) (로컬Y)`| 원하는 영역의 작품 타임랩스를 녹화합니다. 실행시 도안 이미지를 첨부해야 합니다.
| `w!mambo` | ??? |

### 서버 관리자 전용 명령어 (Administrator 권한 필요)

| 명령어 | 설명 |
|---|---|
| `w!setchannel [구역] #채널` | 특정 구역(또는 전체)의 알림을 받을 채널을 지정합니다. |
| `w!setrole [구역] @역할` | 알림 시 멘션할 역할을 지정합니다. |
| `w!setcooldown [시간]` | 같은 구역에 대한 알림 재발송 쿨다운을 설정합니다. (예: `10m`, `1h`) |
| `w!setthreshold [구역] [값]` | 알림이 발동되는 일치율 임계값(%)을 설정합니다. (예: `85` 또는 `독도 88`) |
| `w!disablezone [구역]` | 특정 구역의 감시를 끕니다. |
| `w!enablezone [구역]` | 꺼둔 구역의 감시를 다시 켭니다. |
| `w!pause [시간]` | 서버 전체 감시를 일시 정지합니다. |
| `w!resume` | 일시 정지된 감시를 재개합니다. |
| `w!resetcooldown [구역]` | 해당 구역의 알림 쿨다운을 즉시 초기화합니다. |
| `w!testalert [구역]` | 실제 훼손 여부와 상관없이 테스트용 알림을 강제로 발송합니다. 뒤에 silent를 붙이면 역할 알림 없이 테스트 할 수 있습니다. |

### 개발자 전용 명령어

| 명령어 | 설명 |
|---|---|
| `w!whitelist add/remove/list` | 봇이 활동할 수 있는 서버 화이트리스트를 관리합니다. |
| `w!servers` | 봇이 참여 중인 전체 서버 목록과 통계를 확인합니다. |
| `w!leaveserver [서버ID]` | 특정 서버에서 봇을 강제로 퇴장시킵니다. |
| `w!updatenotif` | 모든 서버에 업데이트 공지를 발송합니다. |
| `w!getinvite [서버ID]` | 서버 초대 링크를 생성합니다. 보안상 거의 사용하지 않습니다. |

> 화이트리스트에 등록되지 않은 서버에 봇이 초대되면, 안내 메시지를 남긴 뒤 자동으로 퇴장합니다.

## 🛠️ 기술 스택

- **Node.js** (>= 18) / **discord.js** v14
- **MongoDB** + **Mongoose** - 서버 설정, 화이트리스트, 녹화 세션·프레임 저장
- **Express** - 헬스체크 및 상태 조회용 웹서버/API
- **sharp**, **pixelmatch**, **pngjs** - 이미지 캡처 및 픽셀 단위 비교
- **canvas**, **chartjs-node-canvas** - 오버레이 이미지·그래프·타임랩스 영상 생성
